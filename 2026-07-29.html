💡 CLAUDE CODE TIP OF THE DAY

Nested Subagents (now 3 levels deep by default)
Use the new depth-3 nesting to run proper multi-store workflows in one Claude Code session: outer agent plans the task → middle agents pull data per store → inner agents write the copy or run the analysis. Each layer is parallel and isolated. Set CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1 in your env if you want the old single-level behaviour. Best for: agency-scale jobs where you're serving multiple RABBIO-style clients from one run.
