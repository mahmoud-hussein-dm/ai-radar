💡 CLAUDE CODE TIP OF THE DAY — Verifiable Done-Criteria

End every agentic Claude Code prompt with:
"You're done when: [specific, checkable outcome]"

Example:
"You're done when: the Shopify webhook fires on test-order-create AND you can see a new Notion row appear in the RABBIO StoryBank."

This single line stops Claude hallucinating completion — it has to actually verify before stopping. Cuts false-positive "task complete" messages dramatically. Works in CLAUDE.md too: add a global done-criterion for your project type.
