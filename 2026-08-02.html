🧠 CLAUDE CODE TIP OF THE DAY

Write "Done when:" at the end of every Claude prompt.

Claude keeps working until it thinks the task is done — but "done" is subjective unless you define it. Adding a verifiable done-criteria line turns vague completion into a pass/fail check. Claude stops gold-plating and you get something you can actually test.

BAD: "Build me a product import flow for my Shopify store."

GOOD: "Build a product import flow for my Shopify store.
Done when: I can paste a Shopify CSV and see 10 products
in the preview table with no console errors."

Works in chat, Claude Code, and any agent prompt. Use it for RABBIO build tasks or when briefing MizanAI clients on what their agent should deliver.
