CLAUDE TIP OF THE DAY: Verifiable Done-Criteria

End every agentic prompt with "Done when:" + a specific, verifiable condition.

Bad: "Write product descriptions for all my SKUs."
Good: "Done when: all 50 product descriptions are saved to output.csv, each is 80-120 words, no two start with the same sentence, and the first 3 rows match the live Shopify titles exactly."

Claude stops drifting, stops over-delivering, and you can verify completion in 30 seconds. Works in Claude Code, API agents, and https://www.google.com/url?q=http://claude.ai&source=gmail&ust=1785125505188000&sa=E tasks alike.
