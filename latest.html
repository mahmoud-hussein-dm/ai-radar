💡 CLAUDE CODE TIP: USE pipeline() NOT SEQUENTIAL AGENTS

Stop running agents one-at-a-time — pipeline() collapses wall time to the slowest single item.

In Claude Code Workflows, pipeline(items, stage1, stage2) runs Item A through all stages while Item B is still in Stage 1 — no barrier, no idle waiting. For a 10-source research sweep (like this brief), sequential agents take 10x the slowest fetch. With pipeline(), it's 1x.

Formula:
const results = await pipeline(

SOURCES,

s => agent(s.fetchPrompt, {label: `fetch:${https://www.google.com/url?q=http://s.name&source=gmail&ust=1785471143433000&sa=E}`}),
r => agent(r.analyzePrompt, {label: `analyze:${https://www.google.com/url?q=http://r.name&source=gmail&ust=1785471143433000&sa=E}`})
)

Item A's analysis starts the moment its fetch finishes — not after all 10 fetches complete.
