💡 CLAUDE CODE TIP OF THE DAY

VERIFIABLE DONE-CRITERIA

Most Claude tasks fail silently — Claude thinks it's done; you're not so sure. Fix it by adding explicit done-criteria to your prompt:

"You are DONE when: (1) the file exists at the specified path, (2) running `node index.js` outputs 'Server started', (3) you've confirmed no TypeScript errors with `tsc --noEmit`."

Claude will self-verify against each criterion before handing back. Works especially well in CLAUDE.md for recurring tasks: define what "done" looks like once and it applies to every session.
